## Agent skills

### Issue tracker

Issues live in GitHub Issues for akemkers/jetdiff, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Coding standards

`CODING_STANDARDS.md` describes how the code is written. When feedback on the code would apply beyond the case at hand, propose a change to `CODING_STANDARDS.md` with the rule it implies. Ask before writing it.

## Releasing

A release is an annotated tag, and the tag's message is the release notes. Write them for users. The steps are in `CONTRIBUTING.md` under Releasing. Ask before pushing a tag.
